# Ngopini Area

Website landing page untuk **Ngopini Area**, usaha kopi segar dalam botol yang praktis dan terjangkau untuk anak kampus.

## Fitur
- Halaman beranda dengan profil singkat usaha
- Daftar varian minuman beserta harga (Aren Latte, Cranberrycano, Salted Caramel Latte)
- Slider testimoni pelanggan (otomatis berganti tiap 10 detik, bisa dinavigasi manual)
- Tombol pemesanan langsung via WhatsApp
- Tautan ke Instagram @ngopini_area
- Tampilan responsif

## Teknologi
HTML, CSS, dan JavaScript murni (tanpa framework). Font dari Google Fonts (Playfair Display dan Poppins).

## Struktur Berkas
- `index.html`: halaman utama
- `LOGO NGOPINI AREA.png`: logo
- `fotoproduk.jpg`: foto produk
- `testimoni1-3.jpg`, `testi4-6.jpg`: gambar testimoni

## Cara Menjalankan
Buka `index.html` di browser, atau gunakan GitHub Pages / hosting statis lain.
